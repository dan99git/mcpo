## Research agent report (done)
- ChatGPT connector auth options: OAuth, No Authentication, Mixed. NO static API key option (developers.openai.com/api/docs/guides/developer-mode).
- Discovery flow: /.well-known/oauth-protected-resource (RFC 9728) -> AS metadata (RFC 8414) -> client reg (DCR/CIMD/predefined) -> auth code + PKCE S256 -> Bearer token. HTTPS mandatory.
- Transports: SSE + streamable HTTP both accepted, streamable HTTP recommended.
- Best-fit build: FastMCP OAuthProxy (serves both .well-known docs, local DCR, PKCE, own JWTs; needs one upstream IdP app). Verified importable in venv (fastmcp 3.0.2): OAuthProxy OK, JWTVerifier OK.
